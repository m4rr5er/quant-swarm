# Quant$warm Terminal — 设计规格 v1

> 图表为中心、AI 嵌入的多智能体量化终端。原型：`src/quant_swarm/uiweb/prototype/index.html`
> 参照系：TradingView（布局/图表交互）、Linear（面板/徽标语义）、Telegram Desktop（对话密度）、Notion（命令面板）。

## 1. 布局

```
┌──────────────────────────────────────────────────────────────────┐
│ Header 44px  标的(⌘K) │ 周期 │ 指标 │ 数据源 │ 右侧:组件在线态     │
├───┬────────────────────────────────────────────────┬─────────────┤
│工 │                                                │ 右坞 360px   │
│具 │  主图区 K线(+EMA/VOL)                           │ AI助手|自选  │
│44 │  副图 RSI(可开关)                               │ 决策|卡片    │
│px │                                                │             │
├───┴────────────────────────────────────────────────┴─────────────┤
│ 底坞 h=224px 可折叠  持仓|成交|决策|组件|风控|学习   [现金·总资产·折叠]│
└──────────────────────────────────────────────────────────────────┘
```

- 左右坞站可拖分隔条调宽（右 280–480px，底 160–400px）；双击分隔条折叠/展开。
- 顶栏 44px、工具轨 44px——TradingView 的精确密度。
- 空态：每个坞站面板定义 empty state（图标 + 一句引导文案），不显示"无数据"裸字。

## 2. 交互模型

| 手势 | 行为 |
|---|---|
| ⌘K / 点标的 | 全局标的搜索弹层（watchlist + 任意代码），Enter 选中 |
| 十字光标移动 | 图左上 OHLC legend 实时刷新；离图回落到最后一根 |
| 工具轨 | 光标 / 水平线(点图标记价位) / 测量(两点间 Δ价·%·bar·量)；可清除 |
| 决策标记 | K线上下箭头；悬停 tooltip 显示 agent+理由摘要；点按→底坞跳到该决策 |
| 底坞 tab | 单击切换；新事件到达未看 tab 时显示小圆点 |
| 聊天 | Enter 发送、Shift+Enter 换行、IME 组合键保护；发送中三点动画；agent 头像色=身份色（investor 琥珀 / quant 绿） |
| 右坞 tab | AI助手/自选/决策；自选行点击=切图；行右 hover ×移除 |
| 错误态 | 请求失败 → 面板内联错误条（琥珀底），不弹 toast 遮图 |

## 3. 组件清单

图表面板（蜡烛+EMA20/50+VOL 副图+RSI 副图）、指标菜单（分组下拉+计数徽标）、指标 pill（图例上可关可设）、画线工具轨、标的搜索弹层、坞站 tab 组、KPI 条（现金/总资产/当日盈亏）、AI 聊天气泡+typing、自选股行（现价+涨跌+迷你 sparkline）、决策条目（action 徽标+时间+agent）、组件心跳行（绿点+延迟）、风险事件行（级别徽标）、学习报告行、表格（sticky 头+悬停+等宽数字）。

## 5. 动效

150–250ms `cubic-bezier(.2,.8,.2,1)`；面板开合带 8px 位移；消息入场 12px 上浮淡入（仅新消息，历史不播）；tab 下划线滑动；`prefers-reduced-motion` 全部降级。

## 6. 状态机（聊天）

`idle → sending(三点) → replied / failed(内联错误条+重试按钮)`。发送中禁止重复提交。
